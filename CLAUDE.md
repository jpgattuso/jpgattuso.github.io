# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

The personal academic website of Jean-Pierre Gattuso (CNRS/Sorbonne Université oceanographer), built as an
R Markdown "distill" website and published via GitHub Pages from the root of `main` (there's a `.nojekyll`
file and no GitHub Actions workflow — the rendered HTML in the repo root *is* the live site). There is no
application code, no package.json, and no test suite; this is a content-maintenance repo.

## Build / render commands

The site is defined by `_site.yml` (a distill/rmarkdown "website" project — see `BuildType: Website` in
`jpgattuso.github.io.Rproj`). `output_dir` is `"."`, so rendering writes HTML straight into the repo root
alongside the source `.Rmd` files.

- Render the whole site: `R -e 'rmarkdown::render_site()'` (or RStudio's Build > Build Website)
- Render a single page: `R -e 'rmarkdown::render_site("publications.Rmd")'`
- Requires the `rmarkdown` and `distill` R packages installed.

There is no lint/test command — "correctness" here means the rendered HTML looks right and links resolve.

## Workflow for content changes

Each page has a source `<name>.Rmd` and a committed, rendered `<name>.html` sitting next to it in the repo
root. **Both are tracked in git and edited together**: change the `.Rmd`, re-render, and commit the `.Rmd`
+ `.html` pair in the same commit (this is the pattern in every prior commit, e.g. "Veytia in press" touches
both `publications.Rmd` and `publications.html`). Commit messages are terse and describe the content change
(author/paper name + status), not the mechanics of editing.

Do not hand-edit the generated `.html` files independently of their `.Rmd` source — always regenerate from
the `.Rmd`.

`_site/` is a **stale** build artifact from before `output_dir` was set to `.` (dated Feb 2023) — it is not
regenerated by the current render workflow and is not what GitHub Pages serves. Ignore it; don't treat it as
a reference for current content.

## Site structure

- `_site.yml` — site-wide config: title, theme (`theme.css`), navbar (Home/Research/Publications/CV +
  institution logos), Google Analytics tag, `distill::distill_article` output.
- `index.Rmd` — home page / bio, written in **English then French** (a full duplicate paragraph in each
  language) — preserve that bilingual pairing when editing.
- `research.Rmd` — list of current/past project links, including to the three "products" pages below.
- `publications.Rmd` — the large one. A chronological bibliography, most recent first, grouped into
  anchored sections (`### <a name="2026">2026</a>`, etc.) in this fixed order: `Submitted` → `In revision` →
  `In press` → descending years back to 1984. A jump-link table near the top of the file links to every
  anchor — **when a new year section is added, add its link to that table too**. Each entry is one
  paragraph: authors, year, italicized title/journal, and bracketed `[Abstract]`/`[pdf]`/`[Link]` links. A
  "Back to Top" image link (`images/backtotop.gif`) follows each section.
- `cv.Rmd` — just links to PDFs in `files/`.
- `seacarb.Rmd`, `tosi_products.Rmd`, `O2015_products.Rmd`, `oosc_products.Rmd` — standalone pages for
  specific projects/initiatives (the R package `seacarb`, and the TOSI/O2015/OOSC initiatives); linked from
  `research.Rmd` but not all are in the main navbar.
- `images/`, `files/` — static assets (photos, logos, PDF CVs) referenced by relative path from the `.Rmd`
  files.
- `theme.css` — distill theme variable overrides (colors, font sizes, header/footer background).
- `eol.html` — a large standalone legacy HTML file with no corresponding `.Rmd` and no inbound links from
  the site nav; treat as archival, not part of the maintained site.
